# MODULE UI — bRAINWAVEz

**Experimentelle Klanggestaltung · Immersive Texturen · Psychoakustik**
**Status:** Production Ready

---

## Übersicht

Der bRAINWAVEz Tab (BRN) ist die experimentelle Klanggestaltungsoberfläche. Immersive Texturen, Psychoakustik, Atmosphäre, generative Layer. Keine Vermischung mit klassischen Effekten.

### Aufbau
- Enable/Disable Toggle
- Mode-Auswahl (Binaural, Isochronic, Stereo Phase)
- Preset-Auswahl (Brainwave-States: Delta, Theta, Alpha, Beta, Gamma)
- Parameter (max 8 sichtbar)
- Solfeggio-Frequenzen
- Clock-Mode (FREE / SYNC / HYBRID)

## Parameter (max 8)

| Parameter | Range | Beschreibung |
|-----------|-------|--------------|
| Carrier | Hz | Trägerfrequenz |
| Beat | Hz | Binaurale Beat-Frequenz |
| Iso Rate | Hz | Isochronic Rate |
| Phase Rate | Hz | Stereo Phase Rate |
| Mix | 0-100 | Wet/Dry Mix |
| Solfeggio Gain | 0-100 | Solfeggio-Lautstärke |
| Solfeggio Q | 0-100 | Solfeggio-Filtergüte |
| Sync Division | Clock-Division | Sync-Mode Division |

## Clock-Modes

| Mode | Beschreibung |
|------|--------------|
| FREE | Freie Laufzeit (unabhängig von BPM) |
| SYNC | Synchronisiert mit VibeCore Sync (BPM-locked) |
| HYBRID | Adaptiv — Sync mit freiem Fallback |

## Design-Regeln

- Dunkler, immersiver Look
- Keine Vermischung mit klassischen FX-Controls
- Generative Layer visualisiert
- Psychoakustische Presets als schnellauswahl
