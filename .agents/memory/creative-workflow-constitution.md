# Creative Workflow Constitution — Agent Reference

## Authority
Creative Master Workflow Senior SUPREMÉ Manager.
This document is the supreme foundation. It sits above all bands, above all architecture, above all code.

## SUPREMÉ DIRECTIVE 001
- Workflow is Law.
- User flow is NOT derived from implementation. Implementation is derived from user flow.
- No code without a defined workflow. No UI built around existing code. No workflow adapted to existing software.

## The Golden Rule
> Der Musiker denkt niemals über die Software nach.
When a user must think "where is this function?" → the workflow has failed → redesign, not patch.

## Executive Design Principle
- One function = one purpose
- One screen = one creative focus
- One gesture = one meaning
- One button = one expected action
- No function operated differently at multiple locations

## 11-Phase Creative Flow (immutable order)
1. IDEE — HOME module, ≤5s to first sound
2. GROOVE — GROOVE module (ROLL · PTN · SND · ARP)
3. BASS — 3D BASS
4. HARMONIE — 3D SYNTH (Chord mode)
5. MELODIE — 3D SYNTH (Lead mode) · GROOVE (ROLL)
6. SOUND DESIGN — SAMPLE FORGE · 3D SYNTH/BASS (Design mode) — optional deep dive
7. FX — FX MIX LAB (FX · MIX)
8. LIVE PERFORMANCE — FX MIX LAB (PERFORM) · GROOVE (ARP) · AI
9. REMIX — FX MIX LAB (REMIX) · SAMPLE FORGE
10. ARRANGEMENT — GROOVE (PTN sequence) · future Arrangement View
11. EXPORT — SETTINGS (LIB + Export)

## Workflow Gate (before any UI decision)
Every UI must answer: Which phase does it serve? Does it interrupt phase flow? Does it force thinking? ≤1 touch within its phase? Exactly one purpose? Is the next flow step visible?

## Release Protocol
No feature design without: phase assignment + workflow description from musician's perspective + WORKFLOW APPROVED by Creative Master Workflow Senior SUPREMÉ Manager.

**Why:** Workflow is Law (SUPREMÉ DIRECTIVE 001). Architecture, DSP-priority order, AI suggestions, and test scenarios all derive from phase context.
