# VibeCoreLiv3 MASTERPROMPT v5.0 — Agent Reference

## Critical Correction vs. v4.0
- "Psychoanalytische 3D-Matrix" and any implied psychological/neurological guarantees are REMOVED.
- **Psychoacoustic Spatial Matrix** = creative sound design tool for immersive spatial audio. NOT a medical or therapeutic device.
- **Binaural Engine** = technical audio feature (ITD, ILD, HRTF, M/S, stereo width, phase, spectral distribution). Whether psychological/neurological effects occur for a given listener remains an open research and creative domain — never communicated as a guaranteed outcome.

## Mission
15-specialist interdisciplinary board. One negative evaluation stops implementation.

## Goal
Fastest, most intuitive, most creative performance groovebox for electronic music.
Speed of musical idea → sound is the quality metric, not feature count.

## Workflow-First Gate (8 questions — all must pass)
1. Increases musical expression? YES
2. Reduces number of steps? YES
3. Understandable without a manual? YES
4. Reachable with minimal gestures? YES
5. Improves live workflow? YES
6. Causes redundant interaction patterns? NO
7. Technically performant? YES
8. Fits product vision? YES
→ Fail = redesign required

## Universal Piano Roll
Single context-aware editor replaces all step sequencers.
- Drum mode: trigger · velocity · probability · ratchet · flam · roll · micro timing · step FX
- Instrument mode: pitch · note length · velocity · glide · automation · chords
ONE editor only — no duplicates.

## One-Touch Principle
Max one navigation · one main view · no duplicate menus · no hidden dialogs · no feature in two places.

## Workflow Consolidation
Actively remove: duplicate editors · redundant menus · duplicate functions · unnecessary dialogs · unnecessary screen changes · inconsistent workflows.

## Audio Engine Requirements
Sample-accurate · deterministic · thread-safe · low-latency · CPU-efficient · modular · platform-independent

## AI
Suggests only: grooves · variations · harmony · arrangement · mixing · performance support.
Every suggestion is optional. AI never replaces creativity.

## Definition of Done (DoD) — task complete ONLY when ALL 10 are true
1. Fully implemented
2. Build succeeds
3. All relevant tests pass
4. No known open blockers
5. Feature usable in UI
6. Workflow same or better
7. Performance same or better
8. Audio quality same or better
9. Code documented
10. Review completed

## Continuous Review (after every feature)
Architecture · Audio · DSP · Workflow · UI · AI · Performance · QA — fix all findings before closing.
